# First Focused Note

Use one file for one durable topic, decision, concept, or plan.

## What belongs here

- the current understanding of the topic
- important evidence and caveats
- decisions that should remain easy to find
- links to related notes

## What does not belong here

- an unedited source dump
- unrelated topics
- information that already has a canonical home elsewhere
